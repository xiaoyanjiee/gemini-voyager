## 已复现缺陷：富文本重复

在 `role="article"`、`class="fai-CopilotMessage"` 中放置 `class="fai-CopilotMessage__content"` 容器，内容如下：

```html
<p>导出测试</p>
<ul><li>UNIQUE_LIST_ITEM</li></ul>
<pre><code class="language-js">const UNIQUE_CODE = 42;</code></pre>
<table><thead><tr><th>Header</th></tr></thead><tbody><tr><td>UNIQUE_CELL</td></tr></tbody></table>
<p><a href="https://example.com">UNIQUE_LINK</a></p>
```

在 Vitest/jsdom 中调用 `extractM365ConversationCapture()`，确认得到 1 条消息，再将该消息传入 `messageToMarkdown()`。统计四个 `UNIQUE_` 标记，每个实际出现两次。

原因：`m365ConversationExtractor.ts` 已把上述结构转成 Markdown；`snapshotAdapter.ts` 把完整文本放入 text block 后，再追加 list/code/table/link blocks；`messageActions.ts` 将所有 blocks 再次拼接。

`M365ExportV2Service` 将这段重复文本作为四种格式的共同输入，因此 JSON、Markdown、PDF、图片导出均存在受影响的代码路径。这是代码层复现与路径分析，未声称四种浏览器下载均已实测失败。
